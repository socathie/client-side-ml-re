Extracting a model shipped as WebAssembly

The brief names the target as "JS / WASM." This runs against agemodel.wasm — a real "age = w·features + bias" model compiled to WebAssembly, with its weights in a data segment. It recovers those weights two ways (statically from the binary, and from live linear memory), reproduces the model outside WASM, and forges the reported age. See RE-FINDINGS.md.
