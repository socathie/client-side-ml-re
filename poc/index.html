WebGazer reverse-engineering demo

A self-contained proof of concept for client-side ML security work: locating an on-device model inside a running browser client, extracting it and running it outside the app, and forging the result. The target is WebGazer (open source, GPL-3.0), an in-browser webcam eye-tracker whose architecture mirrors on-device "estimate X from the camera, nothing leaves the device" products.

It runs with no webcam: WebGazer's real regression object is seeded with a deterministic synthetic calibration set, so the run is identical for everyone. The extraction and tamper code is exactly what would run against a live session. Read REPORT.md for the write-up.
